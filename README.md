# RoomGenius Interior Design Studio — V4

مشروع جامعي تطبيقي لتخطيط الغرف والأثاث، برمجة وتصميم **أحمد فاروق**، طالب بكلية الحاسبات والذكاء الاصطناعي، جامعة وادي النيل.

تحت قيادة وإشراف **الأستاذ الدكتور أحمد النجار**، عميد كلية الحاسبات والذكاء الاصطناعي، والإشراف الفني **البشمهندس خالد والبشمهندسة منى جمعة**. استخدمت صورة الدكتور وشعار الجامعة المرفقين من صاحب المشروع.

## التشغيل في VS Code

1. فك الضغط عن مجلد `RoomGenius_Interior_Studio_V4`.
2. افتح المجلد في Visual Studio Code.
3. ثبّت إضافة **Live Server** (اختياري ولكن مفضل)، ثم انقر بزر الماوس الأيمن على `index.html` واختر **Open with Live Server**.
4. افتح `inspiration.html` من شريط الموقع لتجربة الأفكار والنماذج.

لا يتطلب المشروع بناء حزم npm أو خادمًا لقاعدة بيانات. **اتصال الإنترنت مطلوب للمحرك ثلاثي الأبعاد (Three.js من CDN) وللصور المرجعية والخطوط**. يعمل محرر 2D والمعاينة الإيزومترية الاحتياطية والرسوم المحلية بدون هذه الموارد. بعض المتصفحات قد تحد من مزايا ES modules عند فتح `file://` مباشرة؛ يُنصح باستخدام Live Server.

## التحديثات الجديدة

- هوية بصرية هادئة: عاجي + أخضر مريمي + طوبي، مع خط **IBM Plex Sans Arabic** للعربي و**Manrope** للإنجليزي، وخطوط احتياطية عند عدم توفر الإنترنت.
- استبدال الفوتر الأزرق الثقيل بقسم جامعي فاتح مع صورة الدكتور والشعار واسم الطالب وبيانات الإشراف والغرض العلمي والمحاضرات.
- مكتبة تحتوي على **12 نوعًا** من قطع الأثاث مع صور مرجعية عند توفر الإنترنت ورسومات بديلة محلية، وفلاتر وبحث، وإضافة بالسحب والإفلات.
- إثراء مجسمات السرير والمكتب في مشهد Three.js (السرير: رأس ومرتبة ومخدات ولحاف؛ المكتب: سطح وأدراج وشاشة ولوحة مفاتيح)، مع كومود ووحدة تلفاز ومصباح إضافيين. المجسمات **إجرائية وليست أثاثًا مصوّرًا فوتوغرافيًا**. يمكن استيراد GLB فعلي عبر وظيفة الاستيراد الموجودة.
- أداة لقياس المسافة في المخطط بالمتر، والتحكم بموضع وعرض الباب، وتحليل التداخل ومسارات الحركة، والتراجع/الإعادة والتصدير.
- صفحة ثانية مستقلة **`inspiration.html`** بها 3 نماذج قابلة لفتحها في المحرر، لوحة ألوان تفاعلية، حاسبة مساحة وربط تطبيقي بالمتجهات والمصفوفات والهندسة.
- نافذة تفاعلية لاختصارات لوحة المفاتيح، وتحسين تجربة الموبايل وإظهار التركيز عند التنقل بالكيبورد.

## الملفات

- `index.html`: المحرر الرئيسي.
- `inspiration.html`: مكتبة الأفكار والنماذج.
- `styles.css` و`styles-academic.css` و`styles-v4.css`: التنسيق الأساسي ثم الهوية الجامعية ثم تحسينات النسخة الحالية.
- `inspiration.css`: تنسيق الصفحة الثانية.
- `app.js`: إدارة بيانات الغرفة، المصفوفات والتحويلات، 2D، الحفظ المحلي، السحب والقياس.
- `js/scene3d.js`: المجسمات والإضاءة والكاميرا باستخدام Three.js.
- `js/studio.js`: واجهة الاستوديو والخامات والمشهد والإعدادات.
- `js/insights.js`: تحليل الحركة والتقرير والطباعة.
- `js/enhancements.js`: اختصارات لوحة المفاتيح.
- `js/inspiration.js`: النماذج ولوحة الألوان وحاسبة المساحة.
- `assets/`: شعار الجامعة وصورة الدكتور، ورسم توضيحي محلي ومعاينات فعلية لواجهة المشروع.

## البيانات والخصوصية

الحفظ محلي داخل المتصفح عبر `localStorage`. لا توجد حسابات مستخدمين أو قاعدة بيانات سحابية. يمكن تصدير JSON أو PNG. بيانات الأسعار تقديرية وليست عروضًا فعلية. الصور المرجعية في الكتالوج **ليست** الصور المطابقة بالضرورة للأثاث المجسم.

## حدود النسخة

- لا يوجد محرر جدران متعددة أو شقة كاملة.
- الخوارزمية المقترحة لتوزيع الأثاث بحث هندسي بسيط؛ **ليست AI مولدًا** ولا تضمن التوزيع الأمثل عالميًا.
- تم اختبار المحرر في بيئة Chromium مع منع الموارد الشبكية، ولهذا تم اختبار 2D والمعاينة الإيزومترية الاحتياطية، لكن **لم يتم تأكيد جودة رندر WebGL الفعلي بصريًا** في هذه البيئة.
- لتطوير واقعية الأثاث بشكل جذري: أضف مكتبة GLB مرخّصة بأبعاد صحيحة وخامات PBR وصور مطابقة، واسمح بتنزيلها محليًا بدل CDN.
